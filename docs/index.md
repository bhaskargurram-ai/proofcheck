# proofcheck

Evidence, not authorship: check whether a pull request actually does what it claims, by running its tests on the base and head commits, replaying the linked issue and mapping each claim to evidence, whoever or whatever wrote it.

!!! note "Status: beta"
    Releases are numbered 1.x, but there are no confirmed outside users yet, so details may still change.

```bash
pip install proofcheck-ai
```
